# FLOWDROP

A standalone six-key browser rhythm game. Open index.html directly, serve it locally, or publish this directory as a GitHub Pages repository using the root of the default branch. No build or backend is required.

Use S D F / J K L. Choose Easy, Normal, or Hard before generating the chart. Scroll speed and timing offset are independent settings. User-selected audio stays in the browser. The practice beat is synthesized in JavaScript.

The generator estimates attacks from three frequency bands, applies difficulty-dependent thresholds and spacing, and turns occasional sustained low-frequency sections into holds. It works from the mix, so note selection varies with production and mastering.
